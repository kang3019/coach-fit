# AI 코칭 LLM 공급자 비교 벤치마크

`python-ai-backend/scripts/benchmark_llm.py` 로 공급자(Bedrock, Groq, Gemini, Claude, OpenAI 등)를 **같은 입력**으로 호출해 비교합니다.
서비스 코드(`app.services.ai_coach.generate_coaching_advice`)를 그대로 호출하므로, 실제 앱이 쓰는 프롬프트·파싱·폴백 경로가 측정 대상입니다.

> 이 문서의 결과 표는 **비어 있습니다.** 실제 API 키로 실행한 값만 기록하세요.

## 실행

```bash
cd python-ai-backend
pip install -r requirements.txt

python scripts/benchmark_llm.py --list                       # 대상과 필요한 환경변수
python scripts/benchmark_llm.py --targets dummy --runs 1     # 키 없이 동작 확인
python scripts/benchmark_llm.py --targets groq,claude,openai --runs 5
python scripts/benchmark_llm.py --targets gateway:bedrock-sonnet,gateway:bedrock-haiku --runs 5
```

- API 키는 환경변수 또는 `python-ai-backend/.env` 에서 읽습니다. 키가 없는 대상은 `skipped` 로 표시하고 넘어갑니다.
- `--runs` 는 **시나리오당** 반복 횟수입니다. 시나리오가 3개이므로 `--runs 5` 는 대상당 15회 호출입니다. 유료 API는 호출 수만큼 비용이 듭니다.
- 원본 결과는 `python-ai-backend/benchmark_results/benchmark_<시각>.json` 에 저장됩니다. 커밋하지 마세요(키 관련 에러 문구가 섞일 수 있음).
- `bedrock`(직접 호출)을 측정할 때는 스크립트가 게이트웨이 환경변수를 임시로 제거합니다. 서비스 코드는 게이트웨이 키가 있으면 `bedrock` 도 게이트웨이로 보내기 때문입니다.
- Bedrock 직접 호출은 EC2 IAM Role 또는 `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY` 가 있어야 성공합니다. 자격 증명이 없으면 폴백으로 집계됩니다.

## 측정 지표

| 지표 | 의미 |
| --- | --- |
| 성공률 / 폴백 | 응답이 JSON 으로 파싱돼 정상 처리된 비율. 호출 실패·파싱 실패는 서비스가 규칙 기반 더미로 폴백하므로 그 횟수를 셉니다. |
| 응답시간 중앙값·최대 | 성공한 호출만 대상. 네트워크 지연을 포함한 end-to-end 시간입니다. 표본이 작아 p95 는 계산하지 않습니다. |
| 루틴 3~5개 비율 | 프롬프트가 요구한 종목 수를 지켰는지 |
| 빈 필드 항목 | 모델이 `tip`/`focus` 를 비워 서비스가 기본 문구로 채운 항목 수 |

## 측정하지 않는 것

- **토큰 사용량·비용:** 기존 코드가 응답의 usage 를 반환하지 않습니다. 비용은 각 공급자 콘솔의 사용량 화면으로 확인하세요.
- **조언의 품질:** 자동 지표로는 판단할 수 없습니다. 아래 수동 평가표를 사용하세요.
- **부하·동시성:** 순차 호출만 합니다.
