## 📝 문서 작성 규칙

1. 새 문서는 두 자리 번호 접두어(`08-`, `09-` …)를 붙여 순서대로 추가
2. 파일명은 **소문자 + 하이픈(kebab-case) + 영문 키워드**로 작성 → 한눈에 내용 파악 가능
3. 문서 상단에는 반드시 **제목(H1)** 과 **한 줄 설명** 배치
4. 이 `README.md` 인덱스 표에도 함께 추가할 것
