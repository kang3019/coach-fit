## 1. 프로젝트 비전 (Vision)

### 📌 한 줄 주제
> **"혼자 운동하는 헬스 초·중급자가 중도 포기하지 않도록, 세트별 운동을 3초 만에 간편히 기록하고 최근 부위별 피로도를 분석해 오늘 최적의 운동 루틴을 추천해 주는 AI 피트니스 코칭 앱"**

### 💡 기획 배경 및 문제의식 (Why CoachFit?)
1. **혼자 운동하는 사람(혼헬족)의 막막함**:
   - PT(개인 트레이닝) 비용이 부담되어 혼자 운동을 시작하지만, 대부분 **"오늘 무슨 운동을, 몇 세트, 몇 kg으로 해야 하는가?"**를 몰라 방황하다 1~2달 만에 포기합니다.
2. **기존 앱(Fleek 등)과의 차별화**:
   - **Fleek**은 세련된 다크 테마 UI와 세트/무게 기록의 편리함으로 큰 호응을 얻고 있습니다.
   - CoachFit은 Fleek의 **빠르고 직관적인 운동 기록 UX**를 적극 벤치마킹하면서, 여기에 **"AI 피로도 분석 기반 맞춤형 당일 루틴 추천"**을 결합하여, 주머니 속에 상주하는 '나만의 AI 개인 트레이너'를 제공합니다.

## 2. 사용자 시나리오 (User Scenarios)

### 🎬 시나리오 1: 오늘 뭘 해야 할지 막막한 헬린이 (민수, 23세)
> **[혼자 운동을 시작한 지 2주 된 민수]**가 **[퇴근 후 헬스장에 도착해서]** **[어제 가슴 운동을 했는데 오늘 무엇을 해야 할지 몰라 헤매지 않기 위해]**  
> CoachFit 앱을 열어서 **['오늘의 AI 맞춤 루틴 생성' 버튼을 터치]**하면,  
> **[AI가 "어제 가슴 근육을 사용했으므로 오늘은 하체 및 등 중심 루틴(랫풀다운, 레그프레스 등 4개 종목)"을 추천해 주어 고민 없이 바로 운동을 시작한다.]**

### 🎬 시나리오 2: 헬스장에서 빠르게 세트를 기록하는 직장인 (지수, 28세)
> **[퇴근 후 1시간 안에 효율적으로 운동을 끝내고 싶은 지수]**가 **[헬스장 벤치프레스 앞에서]** **[세트 간 쉬는 시간을 놓치지 않고 다음 무게를 설정하기 위해]**  
> CoachFit 앱을 열어서 **[이전 세트 기록(60kg 10회)을 원터치로 복사해 기록하고 자동 휴식 타이머를 동작]**시키면,  
> **[휴식 90초 후 진동 알림과 함께 이번 세트 목표 볼륨이 실시간으로 누적 반영되어 운동에만 온전히 집중한다.]**

### 🎬 시나리오 3: 정체기 및 오버트레이닝을 점검하는 중급자 (현우, 25세)
> **[주 4회 꾸준히 운동 중인 중급자 현우]**가 **[일요일 밤 집에서 침대에 누워]** **[이번 주 운동 밸런스가 한 부위에만 치우치지 않았는지 점검하기 위해]**  
> CoachFit 앱을 열어서 **['주간 운동 통계 대시보드'와 'AI 피드백 리포트'를 조회]**하면,  
> **[요일별 누적 볼륨 그래프와 함께 "이번 주는 어깨 운동 볼륨이 다소 부족합니다. 다음 주 화요일에 밀리터리 프레스를 추가해 보세요"라는 정밀 분석 조언을 얻는다.]**

## 3. MoSCoW 요구사항 분류

11월 20일 최종 완성 및 데모 시연을 위해 기능 범위를 명확히 한정합니다.

```
┌────────────────────────────────────────────────────────┐
│                      MoSCoW 우선순위 매트릭스          │
├────────────────────────┬───────────────────────────────┤
│ ★ Must Have (필수)     │ 없으면 11/20 출시/데모 불가   │
├────────────────────────┼───────────────────────────────┤
│ ▲ Should Have (권장)   │ 있으면 완성도 대폭 상승       │
├────────────────────────┼───────────────────────────────┤
│ ■ Could Have (선택)    │ 시간 여유 있을 때 구현        │
├────────────────────────┼───────────────────────────────┤
│ ✖ Won't Have (제외)    │ 이번 프로젝트 범위에서 제외   │
└────────────────────────┴───────────────────────────────┘
```

| 구분 | 기능명 | 세부 내용 | 담당 파트 |
| :---: | :--- | :--- | :---: |
| **Must** | **간편 운동 기록 CRUD** | 종목명, 세트 수, 무게(kg), 반복 횟수(reps), 메모 입력/수정/삭제 | 모바일 / Java |
| **Must** | **주간 운동 볼륨 시각화** | 요일별 누적 볼륨(무게×횟수×세트) 집계 및 그래프 표출 (`fl_chart`) | 모바일 / Java |
| **Must** | **AI 맞춤 코칭 & 루틴 추천** | 최근 운동 기록을 분석하여 오늘의 추천 운동 3~4개 및 세트 가이드 반환 | Python AI / 모바일 |
| **Must** | **스마트 폴백 엔진** | 외부 LLM 장애나 API 키 미설정 시에도 즉시 동작하는 룰베이스 코칭 | Python AI |
| **Must** | **시연용 완결형 데모 셋** | 발표 및 포트폴리오 시연 시 즉시 시연 가능한 시드 데이터 및 시나리오 구축 | 팀 공통 |
| **Should** | **운동 목표 설정** | 근비대, 체지방 감량, 근력 증가 목표 선택 시 AI 프롬프트 분기 | Python AI / 모바일 |
| **Should** | **세트 간 휴식 타이머** | 세트 완료 시 카운트다운 타이머(60초/90초) 및 시각 피드백 | 모바일 |
| **Should** | **사용자 프로필 관리** | 닉네임, 운동 구력(초/중/고급), 신체 정보 저장 | Java / 모바일 |
| **Could** | **다크 모드 / 라이트 모드** | 사용자 선호에 따른 테마 전환 | 모바일 |

| **Could** | **월간 운동 캘린더 뷰** | 출석 및 운동한 날 잔디(스트릭) 표시 | 모바일 |
| **Won't** | ~~카메라 실시간 자세 교정~~ | 컴퓨터 비전/MediaPipe 등은 모바일 성능 이슈 및 기한 초과 위험으로 제외 | - |
